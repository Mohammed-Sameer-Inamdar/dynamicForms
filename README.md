# Dynamic Forms

This project is a full-stack web application for creating and managing dynamic forms.

## Project Structure

- **dynamic_forms_react**: Frontend built with React.
- **dynamicFormsExpress**: Backend built with Node.js and Express.
- **Database**: Uses free-tier MongoDB Atlas.

---

## How to Run the Project

### Frontend Setup

1. Open the project in VS Code or your preferred editor.
2. Open a terminal.
3. Run `npm install` or `yarn install` to install dependencies.
4. Start the frontend with `npm start`.

### Backend Setup

1. Open the project in VS Code or your preferred editor.
2. Open a terminal.
3. Run `npm install` to install backend dependencies.
4. Start the backend server with `nodemon index.js`.
